# Walter Karshat

Personal portfolio at https://wkarshat.github.io/.

A dependency-free static site. GitHub Pages serves the root of `main`.

Preview with `python3 -m http.server 8080`, then visit http://localhost:8080.

Edit `index.html`, `style.css`, and `script.js` to update the site. `assets/personal.json` and `assets/fear-ai.json` contain public-only repository snapshots. Update them from the corresponding public GitHub REST endpoints when refreshing the directory. See [SOURCES.md](SOURCES.md) for attribution and editorial scope.
